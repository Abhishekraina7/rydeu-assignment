# RydeU - Assignment
## 🚀 Features

- **User Authentication**
  - Secure login with email and password
  - Session management

- **Date & Time Selection**
  - Intuitive date picker with calendar overlay
  - Dynamic time slot generation based on current time
  - 6-month calendar view for future bookings

- **Modern UI/UX**
  - Clean and responsive design
  - Smooth animations and transitions
  - Platform-specific styling (iOS/Android)

- **State Management**
  - Redux Toolkit for global state
  - Optimized re-renders
  - Type-safe actions and reducers

## 🛠 Tech Stack

- **Frontend**
  - React Native
  - TypeScript
  - Redux Toolkit
  - React Navigation
  - React Native Paper (UI Components)
  - Moment.js (Date handling)

- **Development Tools**
  - ESLint
  - Prettier
  - React Native Debugger

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn
- React Native CLI
- Xcode (iOS) / VS-Code (Windows)
- Mobile phone with Expo Go app installed for testing

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/rydeu-assignment.git
   cd rydeu-assignment
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   # For iOS
   npx react-native run-ios

   # For Android
   npx react-native run-android
   ```
