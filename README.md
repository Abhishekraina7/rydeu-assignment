# RydeU - Car Rental App

A modern, user-friendly car rental application built with React Native, TypeScript, and Redux Toolkit. The app allows users to browse available vehicles, select pickup/drop-off dates and times, and complete their bookings seamlessly.

## 🚀 Features

- **User Authentication**
  - Secure login with email and password
  - Session management

- **Date & Time Selection**
  - Intuitive date picker with calendar overlay
  - Dynamic time slot generation based on current time
  - 6-month calendar view for future bookings

- **Modern UI/UX**
  - Clean and responsive design
  - Smooth animations and transitions
  - Platform-specific styling (iOS/Android)

- **State Management**
  - Redux Toolkit for global state
  - Optimized re-renders
  - Type-safe actions and reducers

## 🛠 Tech Stack

- **Frontend**
  - React Native
  - TypeScript
  - Redux Toolkit
  - React Navigation
  - React Native Paper (UI Components)
  - Moment.js (Date handling)

- **Development Tools**
  - ESLint
  - Prettier
  - React Native Debugger

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn
- React Native CLI
- Xcode (iOS) / Android Studio (Android)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/rydeu-assignment.git
   cd rydeu-assignment
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   # For iOS
   npx react-native run-ios

   # For Android
   npx react-native run-android
   ```
